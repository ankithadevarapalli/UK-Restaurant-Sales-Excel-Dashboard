# UK-Restaurant-Sales-Excel-Dashboard
Interactive Excel dashboard analysing UK restaurant sales, KPIs, performance trends and business insights.

## Project Overview
This project presents an interactive Excel dashboard developed to analyse UK restaurant sales performance, KPIs, trends and key business insights.

## Dashboard Features
- Sales and performance KPI analysis
- Restaurant sales trends
- Interactive charts and visualisations
- Filters and slicers for analysis
- Clear presentation of key business insights

## Skills Used
- Microsoft Excel
- Data Analysis
- Data Cleaning
- PivotTables
- PivotCharts
- Data Visualization
- Dashboard Design

Microsoft Excel | PivotTables | PivotCharts
